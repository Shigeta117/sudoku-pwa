# Zen Sudoku — 広告なし・スマホ向けナンプレ（数独）

**遊ぶ: https://shigeta117.github.io/sudoku-pwa/**

広告なし・登録なしで遊べるナンプレ（数独）の Web アプリです。スマートフォンのブラウザで開き、「ホーム画面に追加」するとアプリのように全画面で起動し、オフラインでも遊べます（PWA）。

## 特徴

- **解き方の難しさで分けた 6 段階の難易度**
  ヒントの数ではなく、解くのに必要な一番難しい解き方で難易度を決めています。どの問題も解は 1 つだけで、勘で埋める必要はありません。

  | 難易度 | 必要な解き方 |
  |---|---|
  | 初級 | シングルだけ |
  | 中級 | ブロックと行・列の関係（ポインティング）まで |
  | 上級 | ペア・トリプル・X-Wing まで |
  | 達人 | Y-Wing などウイング系まで |
  | 鬼 | チェーン系（XY-Chain・AIC） |
  | 極 | チェーンを 12 回以上つなぐ（鬼の問題のうち上位約 3.5%） |

  極は端末で作ると時間がかかりすぎるので、事前に選んだ 200 問を同梱しています。
- **17 個チャレンジ**：最初の数字が最少の 17 個しかない問題。数字の少なさと難しさはほぼ無関係で、17 個の問題の約 8 割は初級〜中級で解けます。そこで「17 個チャレンジ」と、上級以上の技が要るものだけを集めた「17 個チャレンジ（難）」に分けています。記録には数えません。
- **技の練習問題**：道場の各技のページから、その技がいちばん難しい手になる問題を 1 局まるごと解けます。
- **ドパガキモード**（設定でオン）：パチンコ風の演出モードです。正解で玉が出て、10 連続正解で「確変突入」（持ち玉 3 倍）、ミスで「転落」になります。行・列・ブロックが揃うとカットインが入り、残り 9 マスで「リーチ」、3 マスで「激アツ」、クリアで 7-7-7 の「大当たり」です。効果音は Web Audio で合成していて、音声ファイルは使いません。画面全体が光るのは 1 秒に 2 回まで（WCAG 2.3.1 の 3 回より少なく）に抑えています。OS の「視差効果を減らす」がオンなら、揺れと全画面の光を止めます。演出のコードはオンにしたときだけ読み込みます。
- **解き方を教えるヒント**：次に決まるマスを枠で示し、使う解き方の名前（「隠れたシングル」「X-Wing」など）を表示します。もう一度押すと答えの数字が出ます。間違った数字があれば先にそれを知らせます。「解説」を押すと、その技の道場のページが開きます。
- **解法道場**：30 種の解き方を、必要になる難易度の順に解説します。各技には実際の盤面から取った例題があり、決まるマスや消せる候補を自分で探して答え合わせできます。答えでは、形を作るマス・注目する行・列・ブロック・消せる候補を色で示します。
- **入力**：通常入力とメモ（候補数字）、入力の順番（マスを選んでから数字／数字を選んでから同じ数字を続けて置く。設定画面で切り替え）、自動メモ消去、無制限に近い戻す／進む（直近 300 手）、消しゴム。
- **見やすさ**：選んだマスの行・列・ブロック、同じ数字、間違い（オフにもできる）を色で示します。9 個置き終えた数字はテンキーで薄くなります。
- **自動保存**：盤面・メモ・時間・履歴を端末内（localStorage）に保存し、閉じても続きから再開できます。データはどこにも送信しません。
- **ダークモード**：OS に合わせる／ライト／ダーク。

キーボード：`1`〜`9` 入力、`0`/`Backspace` 消去、`N` メモ切替、`H` ヒント、矢印で移動、`Ctrl+Z`/`Ctrl+Shift+Z` 戻す／進む。

## 開発

Node.js 20 以上。

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm test         # テスト（Vitest）
npm run build    # dist/ に本番ビルド
npm run preview  # ビルド結果の確認（Service Worker の動作もここで確認）
```

`main` に push すると GitHub Actions がテスト・ビルドして GitHub Pages に公開します（[.github/workflows/deploy.yml](.github/workflows/deploy.yml)）。`vite.config.ts` の `base` は相対パス（`./`）なので、Vercel などのドメイン直下にもそのまま置けます。

道場の例題は sudoku-core に実際に解かせた途中の盤面から取り出しています。珍しい技は見つけにくいので、事前に生成して `src/data/dojo/` に置いています。足りない技を補うときは `scripts/mine-dojo.mjs` を使います。1 問を最後まで解き、出てきた全部の技の例題をまとめて集めます（使い方はスクリプト冒頭）。特定の技だけ作り直すときは `node scripts/build-dojo.mjs <技のid>` です。同梱した例題は、すべてテストで正解と照合しています。

極・17 個チャレンジ・技の練習問題は `src/data/pool/` に同梱しています。`scripts/mine-pool.mjs` で問題を作るか外部の一覧を読み、sudoku-core で 1 問ずつ採点して JSONL に書き出します。それを `scripts/build-pool.mjs` が選んで、解と一緒に書き出します（使い方は各スクリプトの冒頭）。解が 1 つだけかは書き出すときに全問確かめています。

### 構成

```text
src/
├── App.tsx                     画面・状態管理・キーボード操作
├── components/dojo/            解法道場の画面（一覧・解説・例題の盤面）
├── data/dojo/                  道場の例題（scripts/build-dojo.mjs で生成して同梱）
├── fx/                         ドパガキモード（出来事の通知・玉と確変の判定・光の回数制限・粒子・効果音・画面）
├── data/pool/                  極・17 個チャレンジ・技の練習問題（scripts/build-pool.mjs で選んで同梱）
├── sw.js                       オフライン用 Service Worker の雛形（ビルド時に版と配布ファイルを埋め込んで dist/sw.js に出力）
├── types/sudoku.ts             型と難易度の一覧
└── utils/
    ├── sudokuEngine.ts         難易度の定義・問題生成（sudoku-core）・盤面の判定
    ├── puzzle.worker.ts        問題生成を UI と別スレッドで動かす Web Worker
    ├── puzzleWorkerClient.ts   Worker の呼び出しと、次の 1 問の先読み
    ├── hint.ts                 ヒントの計算と解き方の日本語名
    ├── dojoLessons.ts          解法道場の解説文（技ごと）
    ├── dojoData.ts             道場の例題の読み込み・検証・答え合わせ
    ├── puzzlePool.ts           同梱した問題の読み込み・検証・まだ解いていない問題の選択
    ├── history.ts              戻す／進むの履歴（上限つき）
    └── storage.ts              保存データの読み書きと検証・統計・振動
public/
├── manifest.webmanifest        PWA の設定
└── third-party-licenses.txt    同梱している依存パッケージのライセンス
```

## クレジット

問題の生成・難易度の判定・ヒントには [sudoku-core](https://github.com/komeilmehranfar/sudoku-core)（MIT, © Komeil Mehranfar）を使っています。17 個チャレンジの問題は、Gordon Royle が集めた 17 個の問題の一覧（その後の追加分を含む 49,158 問）から選んでいます。一覧は [tdoku](https://github.com/t-dillon/tdoku)（BSD-2-Clause, © Tom Dillon）の `data.zip` に収録されたものを使いました。ドパガキモードの文字は [Dela Gothic One](https://github.com/syakuzen/DelaGothic)（SIL OFL 1.1、演出で使う文字だけに絞ったもの。`scripts/build-fx-font.mjs` で作り直せます）、持ち玉の数字は [DSEG7](https://github.com/keshikan/DSEG)（SIL OFL 1.1）です。同梱している依存パッケージのライセンス全文は [public/third-party-licenses.txt](public/third-party-licenses.txt) にあります。
